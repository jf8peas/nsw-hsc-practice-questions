# Tasks: Advanced English Unseen-Text Short Answers

**Input**: Design documents from `/specs/008-english-unseen-short-answers/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/api.md, quickstart.md

**Tests**: Included. The plan's Quality Gates table lists a test for every requirement, and the constitution requires authorization and cost-control logic to ship with automated tests. Within each story the tests come first and should fail before the implementation.

**Organization**: Tasks are grouped by user story. The P1 stories (US1, US2, US3 and US6, the starter bank) must be complete and shippable before **Mon 7 Dec 2026**; the P2 stories (US4 the weighted draw, US5 the flag and the offline revision loop) follow. The full 37-paper research (inventory, extraction, OCR for Roseville 2026, rubric drafting, the review approval) is a **separate content task** and is not in this list: only the tooling it writes to is (the bank generator `unseen-build-bank` and the review report `unseen-report`).

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies on incomplete tasks)
- **[Story]**: Which user story the task belongs to (US1 to US6 as numbered in spec.md)
- Include exact file paths in descriptions

## Path Conventions

Single Next.js app at the repository root (`app/`, `components/`, `content/`, `lib/`, `scripts/`, `tests/`, `drizzle/`). The unit folder is `content/units/y12-english-advanced-unseen-texts/`.

## Shell

Run every command through Git Bash, as `CLAUDE.md` requires. From the agent's PowerShell tool:

```powershell
& 'C:\Program Files\Git\bin\bash.exe' -c 'cd /c/Users/johnf/Git/nsw-hsc-practice-questions && npm test 2>&1 | tail -20'
```

Keep the payload in single quotes with no inner double quotes. Scratch files go in `.cline/` and are deleted afterwards. Scripts that read the answer key or the database run as `tsx --conditions=react-server` (see the existing `paragraph-flags` npm script).
